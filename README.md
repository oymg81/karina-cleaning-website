# Clean & Care PRO Website

Modern premium cleaning services website built with React, Vite, and TailwindCSS.

---

# Project Overview

Clean & Care PRO is a residential and commercial cleaning services company.

This project is a complete modern frontend rebuild focused on:

- premium UI/UX
- responsive design
- high conversion
- fast performance
- scalability
- modern frontend architecture

---

# Tech Stack

Frontend:
- React
- Vite
- TailwindCSS
- Framer Motion
- React Router DOM
- Lucide React

Deployment:
- Vercel

Install dependencies:

```bash

```

Run development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```

# Important Notes

- Do not use WordPress
- Build with reusable React components
- Mobile responsiveness is critical
- Optimize for Lighthouse performance
- Use semantic HTML and accessibility best practices
- Google Reviews automatic synchronization remains pending because Google Business Profile APIs currently return a quota of 0 requests per minute for project codingsoft-foes-gbp-prod. Google Support case: 8-0821000041757. Completion remains included once Google restores API access.
